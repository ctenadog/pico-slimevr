# Как запустить pico-slimevr

Короткая инструкция простыми словами: **что делает программа** и **как её
правильно запустить**, чтобы PICO-трекеры заработали через SlimeVR.

---

## 1. Что делает эта программа

Сама она трекеры не читает и драйвер не пишет — протокол PICO закрытый.
Вместо этого она **настраивает и проверяет цепочку** из готовых программ:

```
PICO Motion Trackers (пояс + щиколотки)
        │  шлем PICO
        ▼
PICO Connect (ПК)      отдаёт трекеры в SteamVR как Vive-трекеры
        ▼
SteamVR                видит их как Vive Tracker
        ▼
SlimeVR Feeder App     забирает позиции из SteamVR
        ▼
SlimeVR Server         считает скелет по пропорциям тела
        ├── драйвер SlimeVR   → эмулирует Slime-трекеры в SteamVR
        └── VRChat OSC        → трекеры напрямую в VRChat
```

Программа умеет:

* **проверить** — все ли звенья на месте и настроены;
* **починить** — включить передачу тела, подключить драйвер SlimeVR,
  выставить роли трекеров;
* **откатить** — вернуть все файлы как было.

Меняет она ровно три файла (и перед каждой правкой делает копию `.bak`):

| Файл | Что меняет |
|---|---|
| `%APPDATA%\PICO Connect\settings.json` | `bodyTracking = true` |
| `%LOCALAPPDATA%\openvr\openvrpaths.vrpath` | путь к драйверу SlimeVR |
| `<Steam>\config\steamvr.vrsettings` | роли трекеров (`TrackerRole_*`) |

## 2. Что установить заранее

Поставьте три программы (по порядку):

1. **PICO Connect** — стример PICO для ПК (официальный сайт PICO).
2. **SteamVR** — в Steam: *Library → Tools → SteamVR*. Запустите один раз,
   чтобы создались его файлы.
3. **SlimeVR Server** — установщик с <https://slimevr.dev>. При установке
   оставьте включёнными галочки **SteamVR Driver** и **SlimeVR Feeder App** —
   именно они и делают всю работу.

Пока эти три программы не установлены, `pico-slimevr` напишет, что ничего
не найдено, — это нормально.

---

## 3. Как запустить

Есть два способа. Выберите любой.

### Способ А — готовый файл `.exe` (проще всего, Windows)

1. Скачайте `pico-slimevr.exe`:
   откройте https://github.com/ctenadog/pico-slimevr/actions, выберите
   последний успешный запуск **build** и скачайте артефакт
   **`pico-slimevr-windows`** (внутри — `pico-slimevr.exe`).
2. Положите `.exe` в любую папку, например на рабочий стол.
3. Откройте **PowerShell** в этой папке (Shift + правый клик по папке →
   «Открыть в Терминале» / «Открыть окно PowerShell здесь»).

Дальше вводите команды по одной:

```powershell
.\pico-slimevr.exe                 # проверить состояние (ничего не меняет)
.\pico-slimevr.exe --dry-run       # показать, что будет изменено
.\pico-slimevr.exe --fix           # применить безопасные исправления
```

Если хотите без команд — есть окошко:

```powershell
.\pico-slimevr.exe --gui
```

### Способ Б — через Python (если установлен Python 3.10+)

```bash
pip install -e .
pico-slimevr            # проверить
pico-slimevr --dry-run  # посмотреть, что будет изменено
pico-slimevr --fix      # починить
pico-slimevr --gui      # графический интерфейс
```

## 4. Правильный порядок действий

1. **Откалибруйте трекеры на шлеме.** Наденьте трекеры (пояс + 2 на
   щиколотки), включите их и пройдите калибровку в приложении Motion Tracker
   на шлеме. Для ПК это обязательно.
2. **Закройте SteamVR** (если запущен) — роли трекеров меняются только при
   выключенном SteamVR.
3. **Запустите `pico-slimevr --fix`.** Он включит передачу тела, подключит
   драйвер SlimeVR и выставит роли трекеров.
4. **Запустите SteamVR**, затем **SlimeVR Server**. Feeder App сам подхватит
   трекеры из SteamVR.
5. **Проверьте:** SteamVR → *Settings → Manage Add-ons* — драйвер `SlimeVR`
   включён; SlimeVR → *Settings → SteamVR Trackers* — нужные виртуальные
   трекеры (Waist, Feet) включены.
6. **Сделайте Reset** в SlimeVR, стоя прямо.
7. **В игре** нажмите «Calibrate FBT» и встаньте в T-pose.

Готово — игра видит трекеры как SlimeVR, со скелетом и авто-пропорциями.

---

## 5. Как проверить, что всё получилось

* `pico-slimevr` (или `.\pico-slimevr.exe`) показывает галочки `[OK]` по
  каждому пункту.
* В SteamVR трекеры видны и им заданы роли (Waist, Left foot, Right foot).
* В SlimeVR трекеры двигаются, когда вы двигаете ногами.

Полезные команды:

```bash
pico-slimevr --explain    # схема и список изменяемых файлов
pico-slimevr --roles      # заново выставить только роли трекеров
pico-slimevr --ports      # проверить порты VRChat OSC (9000/9001)
```

---

## 6. Если что-то не так

| Симптом | Что делать |
|---|---|
| «Ничего не найдено» | Не установлены PICO Connect / SteamVR / SlimeVR — поставьте их (раздел 2) |
| Трекеры не видны в SteamVR | Нет профилей `swift` или не откалиброваны на шлеме (см. README) |
| Видны в SteamVR, игра игнорирует | У игры нет FBT или включены лишние трекеры — оставьте Waist + Feet |
| В SlimeVR трекеров нет | Не запущен Feeder App или драйвер SlimeVR выключен в Add-ons |
| Пояс «уезжает» | Reset в SlimeVR и калибровка FBT в игре |

---

## 7. Как всё убрать (откат)

```powershell
.\pico-slimevr.exe --uninstall --dry-run     # посмотреть, что будет откачено
.\pico-slimevr.exe --uninstall               # откатить (файлы вернутся из .bak)
.\pico-slimevr.exe --uninstall --purge-backups   # откатить и удалить сами .bak
```

`--uninstall` возвращает все три файла в исходное состояние. Саму программу
удаляют так:

```bash
pip uninstall pico-slimevr
```

PICO Connect, SteamVR и SlimeVR инструмент не удаляет — их убирают их
собственными деинсталляторами.
